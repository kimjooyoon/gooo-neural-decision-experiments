# Follow-up: useful bounded judgment and typed source context

The fixed-channel comparison is complete and regressed continuation attempts.
First-shot accuracy is descriptive. The development objective is useful partial
assembly with finite tests, honest uncertainty, small memory and bounded work.
The following are proposed controlled studies, not completed experiments or new
independent intention counts. Register their exact contracts before training.

## 1. Separate intention evidence from finite-test ambiguity

The current objective fits finite best sets, which can contain both legal paths
when a sparse test cannot distinguish them. Keep that ambiguity visible. Compare
the existing finite-target objective with an explicitly separated intention-label
auxiliary head. Only synthetic source-bound intended labels may supervise the
auxiliary head; tests cannot be silently relabeled from model suggestions.

Measure known intention agreement, finite cases passed, same-wrong bilingual
pairs, abstentions, added legal attempts and total predictions. Report sparse and
full contracts separately. Use the existing v1 baseline, matched initialization,
equal optimizer budgets and group splits. Repeated views remain development data.
An auxiliary head requires a new model schema and cannot reuse old metadata.

## 2. Replace text context with compiler-produced bounded structure

The current context channel is text ngrams, not typed IR. Build a Go adapter for
canonical bounded facts: node kind, available locals, assignment targets, legal
operand orders, branch relations and root order. Encode facts into fixed arrays;
keep Korean/English intent in its own bounded channel. Reject overflow explicitly.
Never let a model invent identifier bindings or legal options.

Study a single context allocation change at a time. Preserve exact channel
isolation and Go/export parity. Add metamorphic cases where only an identifier
spelling changes, an available binding changes, or a legal option is removed.
These are generated views of their source intentions, not independent tasks.

## 3. Adopt an explicit experimental ABI in the native compiler

SDK 0.2.8 correctly rejects the split-v2 feature version before inference.
An experimental SDK successor can expose the new codec behind exact versioned
metadata without selecting its weights by default. Native integration must
construct the bounded source context from verified typed structures. Currently
the initial ranking path receives caller intent only; accepting metadata alone
would not establish useful context integration.

Capture model-off, existing-v1 and explicit-v2 native calls with source, model,
legal-option and test digests. Execute the exact emitted Go with an independent
authored oracle. Compare partial completion and continuation attempts before
and after additional tests. Record stage time, whole-child CPU/RSS and measured
utilization separately. Exercise cancellation, parallel calls and disconnected
determinism. No extra model call is permitted merely to repeat already available
finite legal-path enumeration; record every call if reranking is actually needed.

## Publication policy

Publish preregistrations, source, finite denominators, experimental weights,
negative comparisons and immutable verification receipts to the existing public
GitHub/HF repositories. Keep prior revisions intact. Training may use GPU, while
the runtime and orchestration remain Go. The core model is selected only after
its intended bounded use improves measured work; a high first-shot score is not
a prerequisite for publishing a useful experiment.
