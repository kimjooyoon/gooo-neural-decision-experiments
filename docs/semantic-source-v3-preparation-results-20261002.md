# Own small Gooo model: source ABI and fresh curriculum preparation

This preparation phase is complete; it contains zero new optimizer updates or
weight exports. Frozen training and native evaluation follow separately. Older
weights and their negative results remain unchanged.

## Deployed compiler connection

Native main `f4813dc6251037767c8cff7295ccfdab2b044ff2` binds the original
Gooo source, projects 64 bounded typed structural fields, and preserves the
complete Korean/English natural suffix. Explicit `semantic_context_intent_v3`
uses the existing own 256/48/8 model architecture: 12,728 parameters and a
1,248-byte prediction workspace. Optional representation overflow preserves
deterministic continuation. The default feature version remains v2.

[Feature PR 1135](https://github.com/kimjooyoon/meta-ontology-go/pull/1135) and
[main PR 1136](https://github.com/kimjooyoon/meta-ontology-go/pull/1136) merged
normally after all six canonical checks and independent Go proof verification.
[Main push CI](https://github.com/kimjooyoon/meta-ontology-go/actions/runs/36912740332)
also passed. Main still requires six machine checks, strict status binding and
admin enforcement; its approving review count is zero.
[SDK v0.2.11](https://github.com/kimjooyoon/gooo-decision-runtime/releases/tag/v0.2.11-experimental)
is public. Fresh binaries pin the clean main source and SDK.11.

Warm structural projection measured 749.9–800.2 ns/op with zero heap allocation
on M4. This is one projection kernel, not whole compiler/model latency or zero
total RAM.

## Fresh source-bound data

Six composition families combine references, assignments, subtraction,
predicates, branches and schedule choices. Each has four desired masks, 48
parameter configurations and Korean/English views. The independent Go oracle
preserves 16 ordered int64 cases including intentional wraparound and duplicate
inputs. There are 1,152 program/contract groups, 2,304 bilingual function views
and 4,608 decision rows per feature arm: 9,216 rows total. These counts include
language/parameter variants and are not independent intention counts.

The valid collection made 4,608 zero-prediction native context exports. Streaming
audit reconstructed every finite target and checked raw bytes, source, complete
input, test and feature hashes. Maximum complete input was 329 bytes. Export
child wall median/p95 were 5.760/6.332 ms; inference, host CPU increase and RSS
were not measured in this collection.

The audit retained 16 v3 and 20 v2 byte-identical input texts with conflicting
finite coordinate targets. There are 336 distinct v3 and 1,600 distinct v2 input
texts, so absolute conflict counts cannot establish improved model quality.
Targets and templates were not changed after this observation. Finite ties
and source compression limits remain in the curriculum.

The first 4,608-export collection failed original-byte capture audit: embedding
`json.RawMessage` dropped the native encoder's final newline. That collection is
retained and excluded from training. The corrected capture stores original
bytes as base64 and passed a fresh audit. Actual exports across both attempts
total 9,216; only the valid attempt supplies training rows.
