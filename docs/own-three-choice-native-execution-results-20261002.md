# Actual three-choice Gooo generation and compiled Go results

## Completed frozen native phase

The original five-policy phase completed **640 actual Gooo generations,
640 actual Go compile-and-run invocations and 10,240 ordered function outputs**.
Every output agreed with its independent authored contract. There were **1,760
actual native model predictions**, no new optimization updates and no default
model promotion. This is the independently initialized own Gooo model study;
Laya or other pretrained weights do not initialize these students.

Collection source is `7184fe01327f491aad98027d97fc973e2f0ae645`. Native main is
`774eabb226f88a317c523ce4efa24a08032066a9`, public SDK
`v0.2.13-experimental`, with Go 1.27.1 for generation and independent compilation.
Executable hashes and exact model hashes are retained in preexecution.

The source/dataset/model/plan/input/SDK-path/full-frontier/compiled-output audit
reconstructed all 640 pairs using **zero additional native, Go or model calls**.
Its public receipt is
`publication/own-three-choice-native-execution-audit-20261002.json`. This phase
adds 43,696,881 original raw bytes, in 1,284 closed files. Whole retained raw study
evidence is 990,581,179 bytes under the separate 2-GiB storage amendment. The
original SDK cap failure and the earlier complete SDK evidence remain unchanged.

Selected actual mean recorded model prediction time is 26.743 microseconds over
423 calls. That includes calls inside fresh native processes and full recorded
feedback inputs; the earlier warmed kernel microbenchmarks have a different
measurement scope. Its compiler internal median is 2.322 ms: plan preparation
0.328 ms, source binding 0.553 ms, model load 0.219 ms, context projection 0.312 ms,
bounded search 0.512 ms and final emission 0.261 ms. Medians of phases are not
additive medians of their total.

Disconnected model load and context projection are exactly zero in every
captured request. Its compiler internal median is 1.492 ms. These source-bound
native calls currently pay a model-load/context cost per process. A retained
model API exists in the compiler, but this operational command-line phase does
not measure a persistent process or its potential latency improvement.

Collector wall time was 331.996 seconds and its own CPU time 40.630 seconds
(12.238% of one core), including prerequisite auditing, collection and recording.
Collector lifetime peak RSS was 192,544,768 bytes (183.625 MiB). Codegen and Go
compile/run child CPU/RSS are separate. A child's maximum RSS is not simultaneous
process-tree memory or model tensor RAM; none of these measurements establishes
a causal change in the host's overall utilization.

The 768/24/8 FP32 model stores 74,624 weight bytes and uses a fixed 3,200-byte
request workspace. Those tensor quantities differ from compiler process RSS.
Ternary export storage remains 3,854 weight bytes plus metadata; no quantized
variant was substituted into this original FP32 native policy set.

The reused `finite_counts` JSON structure retains legacy field names containing
`sdk_session_wall`; in this native report their values are captured native
codegen child wall time. Native timing conclusions above use the explicitly
named `actual_codegen_children`, `actual_compile_and_run_children` and
`native_internal_phase_timing` fields.

## Language capability boundary

This validates model-ranked complete paths for the eight authored families:
operand orientation, local references, assignment targets, statement order,
conditional and nested branch layout, comparison and Boolean references.
The model selects legal authored typed alternatives bound to Gooo source; it does not invent an
arbitrary body AST. Source bindings and independent execution receipts connect
observations back to authored Gooo contracts.

The compiler's explicit shared Gooo declaration/generated receipt schema,
general capability discovery, arbitrary program synthesis and broader
multi-activity execution remain separate language requirements. This research
phase does not close those compiler issues or claim universal completeness.
