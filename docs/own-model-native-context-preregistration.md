# Own-model native Gooo context dogfood

Publish source and this protocol before trained-model compiler calls. Reuse the
subtraction, conditional assignment and compound reference/branch/order intentions
already used in prior studies. Zero new independent intentions, training steps or
upstream Laya calls. All variants are independently initialized own-model exports.

## Fixed matrix

Use the three immutable split-v2 FP32/PTQ/QAT exports from
`runs/split-context-judgment-mps-20261001/v2/models` and disconnected control.
Four subtraction documents reuse `studies/own-model-sdk-context-v1`: English/Korean
and sparse/full contracts. Sparse is input 2 -> 0 with one candidate; full adds
input 3 -> 1 and allows two. Source is the original `input-2` body.

Two conditional documents reuse the compiler's full seven-case English/Korean
fixtures, with six decisions and at most 64 candidates. One mixed-language
compound document reuses three decisions, three cases and eight candidates.
A final representation-bound probe reuses conditional Korean source/plan, replaces
the first intention with 150 copies of `가` (450 bytes), and changes the last
expected value to 999, as in prior partial-contract studies. This synthetic text
is a representation probe, not a new meaningful intention. Its model cells request
eight-attempt batches and two feedback rounds; compiler context overflow must
skip optional ranking/feedback and emit the best deterministic partial body.

Eight documents times four arms = 32 actual native child calls. Expected initial
model predictions: 57 (12 subtraction, 36 conditional, 9 compound); three model
representation declines make zero predictions. No feedback inference is expected.
There are 120 selected finite cases across repeated cells. Keep every negative
choice, type rejection, attempted case, added candidate and partial denominator.
These are reused finite observations, not an independent language benchmark.

## Evidence and boundaries

Require a clean Go 1.27.1 native binary built from the specified source revision,
SDK v0.2.9-experimental, source binding before context/prediction, exact model pins,
zero repository writes, native type checking and replay. Preexecution records bind
binary, source/protocol, input/source files, models and revision before first call.
Compiler contexts must link original plan, source semantic digest, stable ID and
original/natural intent hashes. Sparse/full input hashes should agree for identical
plan/intent, showing no authored test outcomes in initial context.

Execute every selected emitted Go package in a separate bounded process using
all its declared inputs (32 Go execution processes, 120 function invocations).
Independently reconstruct each typed candidate and check captured actuals/pass
flags; compare actual compiled Go values with native finite receipts. Arithmetic
for the subtraction intention also independently checks forward/reverse answers.
Audit rereads all captures without model calls. Retain raw captures and executions.

Record context preparation, per-prediction nanoseconds, bounded search, total
native timing, child wall/user/system CPU and child peak RSS. Process CPU over wall
is a one-core-equivalent ratio, not host CPU utilization or a causal speedup.
Each process has bounded output, cancellation and process-group termination.
No default promotion, arbitrary synthesis, full-domain proof or new GPU training
claim. The previous split-feature regression and old native ABI rejection remain
published. This study tests the newly connected source-bound execution path.
