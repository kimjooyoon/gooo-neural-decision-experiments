# Three-choice native Gooo generation and actual Go execution

## Original scope and immutable prerequisites

This implements the native phase of
`own-three-choice-completeness-preregistration-20261002.md` without changing its
authored curriculum, models, selector or operational denominators. The separately
published storage amendment remains necessary: the original 768 MiB SDK failure
is preserved, and total retained raw study evidence is bounded by 2 GiB.

Native main is `774eabb226f88a317c523ce4efa24a08032066a9`, using the unreplaced
public SDK `v0.2.13-experimental`. Gooo, its sibling body worker and the emitted-Go
execution compiler must have clean Go 1.27.1 build information. Their complete
executable byte hashes and sizes are recorded before operational calls.

The original complete SDK prerequisite contains 11,264 unique sessions. Its
independent reconstruction is rerun before native collection, with zero new
operational predictions. The original calibration-selected candidate remains
`set-feedback/fp32`; development observations cannot change it.

Development configuration 20 contains exactly 128 ordered views: eight authored
families, eight goal masks and Korean/English views. Five original policy slots
run: calibration-selected, uniform-initial FP32, set-initial FP32, set-feedback
FP32 and disconnected. Selected and set-feedback are separate preplanned slots
using the same immutable model. They are not independent model arms or new
authored experiment ways. Full scope is **640 real Gooo generations, 640 actual
compile-and-run invocations and 10,240 ordered function outputs**.

## Original declaration, projected input and emitted code

Each request reconstructs the frozen authored typed plan and source. Its original
fallback source SHA, full plan document SHA and all 16 ordered case hashes must
match the native receipt. Source binding, type checking, deterministic replay,
zero repository writes, native revision and finite final case results are
required. The original compiler source is not edited during this phase.

The original caller text starts with `caller context;intent:`. The SDK's
`ThreeInput` deliberately returns its complete length-framed text together with
an unsupported-canonical-ABI error. The compiler retains those full original
bytes, while constructing the separate source-projected canonical model input.
The auditor verifies the complete original text/hash/byte count/decision count
and separately verifies all three ordered canonical part hashes and byte counts,
original/ranked plan hashes, model metadata and source semantic binding.

An initial local validation incorrectly required the original caller text to
pass the model ABI. Its retained diagnostic showed the compiler had preserved
all 201 original bytes. The auditor was corrected against those actual bytes and
the public SDK implementation. No input is truncated and no native source
contract is weakened.

Model predictions rank eight complete legal typed paths. One candidate is tested
per advance; up to seven actual failure feedback steps can reconsider the path
before final native emission. Every native candidate, initial proposal and call
count must match its previously recorded SDK observation. The auditor independently
recomputes candidate arithmetic, full frontier and feedback causality.

The native generated Go is saved as its exact original stdout. A fresh temporary
module compiles and runs that source with all 16 independently authored inputs.
Exact emitted-Go SHA, actual stdout, ordered values and process measurements are
recorded separately. The fresh module preserves ordinary Go build-cache
behavior; this is not a claim of 640 cold cache builds.

Disconnected runs must have no model context, no model predictions and zero
model-load/context-projection time. Model-assisted legal-path ranking grants no
repository write authority or default model promotion.

## Bounded collection and measurements

Every child has a 30-second deadline and one-second pipe wait bound. Darwin/Linux
cancel the entire process group. Output is bounded to 1 MiB per native capture
and 128 KiB of stderr. Overflow fails explicitly and retains the previously
captured prefix; overflowing output is not described as complete.

Before each pair and before its independent Go execution, at least 4 GiB free
storage is required. Raw accounting includes every prior original study file.
Both per-pair records and terminal receipt space are reserved. Original stdout
is persisted before decoding or dependent execution. Each stopped phase retains
its exact ordered prefix and terminal counts; it cannot be overwritten or
silently restarted.

Numeric policy measurements use fixed `[128]` arrays and seven `[128]` phase
arrays. Report child wall/CPU/max RSS separately for codegen and compilation/run,
plus compiler plan preparation, source binding, model load, context projection,
bounded search, final emission and total time. Median is the midpoint of entries
63/64 and p95 is nearest rank entry 121. CPU uses one-core normalization. Child
max RSS is the OS resource measurement, not simultaneous process-tree RAM,
model tensor memory or a causal increase in host utilization.

## Validation and independent replay

Optional local integration validation completed 32 actual native/compiled pairs
across all eight families and both languages, using selected and disconnected
policies. All 512 actual outputs matched the independent contracts; there were
31 actual native model predictions. This validation is separate from the 640
operational pairs. Its retained raw outputs can be replayed after auditor changes
with zero additional native, Go or model calls.

Race validation covers SDK identities, original caller byte preservation,
fixed-array metrics, output overflow, bounded cancellation and receipt mutations.
The local optional integration uses explicit pinned binary environment variables.
CI does not treat a skipped optional local integration as proof of operational
completion. The future public native raw appendix is independently reconstructed
in CI using the zero-call native audit mode.

Collection command, from a clean publicly pushed source revision:

```sh
GOTOOLCHAIN=go1.27.1 go run ./tools/own-three-sdk-study --native \
  --dataset runs/own-three-composition-curriculum-fixed-20261002/dataset.jsonl \
  --prefix runs/own-three-sdk-study-20261002 \
  --sdk-tail runs/own-three-sdk-storage-tail-20261002 \
  --output runs/own-three-native-execution-20261002 \
  --source-revision "$GOOO_STUDY_REVISION" \
  --native-binary "$GOOO_NATIVE_BINARY" --go-binary "$GOOO_GO_BINARY"
```

After the actual collector terminates, use `--native-audit-report` with the same
dataset/prefix/tail/output paths and omit `--native`. Auditing invokes no native
compiler, generated Go or model predictions. Completed receipts must reconcile
the original five policies and full denominators; an incomplete captured prefix
does not establish the native phase's completeness.
