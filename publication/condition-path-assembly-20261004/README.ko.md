# Gooo의 조건식과 본문 조립

2026-10-04, macOS arm64와 Go 1.27.1에서 관측했습니다. 컴파일러 후보는 소스 `a7dfad39f10ba6591ea013763d2c1e87f8e50322`, SDK `v0.2.21-experimental`로 빌드했습니다. 이 SHA256은 측정에 쓴 dev 빌드의 지문입니다. 이후 main [`7da0972`](https://github.com/kimjooyoon/meta-ontology-go/commit/7da097229caf39aa64a277fdc2c200256c834b9c)은 같은 소스 트리를 담고 있습니다.

이 실험은 범위를 좁혀 두 가지를 확인합니다. 작은 로컬 모델이 타입이 정해진 Gooo 본문 경로 중 하나를 고르는 데 도움이 되는지, 첫 선택이 틀렸을 때 유한 테스트가 올바른 경로를 찾는지입니다.

## 언어 변경

소스 레시피가 `>`, `>=`, `!=`, 불리언 `!` 조건식을 받습니다. 컴파일러는 이를 기존 타입 조건·동등 비교 구조로 정규화합니다.

- `a > b` → `b < a`
- `a >= b` → `b <= a`
- `a != b` → `(a == b) == false`
- `!condition` → `condition == false`

Gooo SDK 연산은 추가하지 않았습니다. 예제 본문은 조건식, 지역값, 대입, 분기와 반환을 함께 구성합니다. 자세한 내용은 [소스 경로 레시피 가이드](https://github.com/kimjooyoon/meta-ontology-go/blob/main/docs/source-path-recipes.md)와 [기능 PR #1210](https://github.com/kimjooyoon/meta-ontology-go/pull/1210)을 참고하세요. 동일한 dev 트리를 [PR #1212](https://github.com/kimjooyoon/meta-ontology-go/pull/1212)로 `main`에 병합했습니다. 독립 증거 검증은 통과했습니다.

## 선택 실험

원본 함수는 `first = input + 2`, `second = input * 2`를 계산하고, 둘 중 하나를 분기 기준으로 선택한 다음 조건에 따라 값을 조정합니다. 레시피는 지역값 참조, 분기 구성, 독립 선언 순서라는 세 가지 이진 선택을 열어 전체 여덟 후보를 선언합니다.

이번 의도는 두 번째 지역값을 분기 기준으로 사용합니다. 모델은 기본 선택인 mask 0을 먼저 제안했습니다. 필요한 mask 1은 확률 순위 3위였습니다. 유한 TDD 탐색은 0, 4, 1을 평가한 뒤 필요한 본문을 선택했습니다. 결정론 탐색은 0, 1을 평가했습니다. 두 경로 모두 선택 사례 **5/5**를 통과했고 같은 결과 digest를 냈습니다.

별도 컴파일 실행 사례는 양쪽 모두 **11/11**을 통과했습니다. 그중 6개 입력은 선택 사례와 겹치지 않습니다. 이것만으로 해당 입력이 학습에서 보이지 않았다고 말할 수는 없습니다. 모드별 저장 영수증에는 요청 두 건이 들어 있습니다.

처음 작성한 oracle은 입력 5의 기대값을 25로 적었습니다. 본문 계산식의 값은 24이며 생성 함수도 24를 반환했습니다. 잘못된 기대값으로 나온 최초 4/5 부분 결과를 숨기지 않고 보존했습니다. `initial-oracle.json`, `initial-oracle-error-generation.json`, `oracle-correction.json`에서 그 수정 과정을 볼 수 있습니다. 고친 뒤 모델·결정론 양쪽 선택 결과는 5/5였습니다.

## 완전성 범위와 자원

수치의 분모를 합치지 않고 경계별로 보고합니다. 타입 본문 동치 증거, 선택 사례 5/5, 컴파일 실행 사례 11/11을 확인했습니다. **전체 완전성 점수는 계산하지 않았습니다.** 이 유한 입력만으로 모든 `int64`, 명시되지 않은 자연어 의도, 다른 작업이나 Gooo 문법 전반을 증명하지 않습니다.

새 `gooo body-codegen` 프로세스 10개씩, 실행 순서를 번갈아 측정했습니다. 아래 직접 코드젠 수치에는 생성 Go의 컴파일·실행 비용이 포함되지 않습니다.

| 10회 중앙값 | 소형 모델 | 결정론 |
| --- | ---: | ---: |
| 코드젠 전체 프로세스 시간 | 11.087 ms | 8.981 ms |
| 프로세스 CPU 시간 | 10.098 ms | 8.609 ms |
| 프로세스 최대 RSS | 21,037,056 B | 20,201,472 B |
| 한 코어 기준 프로세스 CPU/벽시계 시간 | 94.69% | 95.11% |
| 로컬 모델 판단 | 21.275 µs | 0 |

이 과제에서 모델 경로는 최대 RSS 중앙값이 약 0.80 MiB, 프로세스 CPU 시간이 1.489 ms 더 높았습니다. 두 경로 모두 짧은 실행 동안 한 코어에 가까운 CPU를 썼습니다. 이 비율은 컴퓨터 전체 CPU 이용률이 아닙니다. 모델 판단 자체는 전체 실행 시간보다 매우 짧았고, 후보 평가를 한 번 더 만들었습니다.

`body-path-run --repeat 2 --timing`의 각 요청은 11/11과 네이티브 실행 2회를 기록했습니다. 첫 응답은 모델 1,418.228 ms, 결정론 1,295.898 ms였고, 아티팩트를 재사용한 두 번째 응답은 각각 28.255 ms, 26.700 ms였습니다. 각 모드의 단일 쌍 관측이며 컴파일·캐시 상태 차이가 있어 일반적인 속도 차이로 해석하지 않습니다.

가중치 변경과 추가 학습은 없었습니다. 모델은 선택 가능한 대안을 제시했고, 선언된 사례를 만족하는 본문은 유한 테스트가 판별했습니다. 이번 작업에서는 결정론 경로가 후보를 적게 평가하고 더 빨랐습니다.

## 재현 자료

전체 원본, 레시피, 선택·실행 사례, 생성 영수증, 네이티브 실행 영수증, 10회 자원 측정과 측정 도구를 이 디렉터리에 보존했습니다. 영어 [README](README.md)에 Go 1.27.1 재현 명령이 있습니다. `SHA256SUMS`로 묶음의 무결성을 확인할 수 있습니다.

재현할 때 Gooo 실행기에 넘기는 Go 경로도 확인해야 합니다. 로컬 기본 `go`가 1.26.5이고 실험이 1.27.1을 요구하면, `command -v go`만 넘겼을 때 본문 생성은 되더라도 실행 단계가 도구체인 검사에서 중단됩니다. 현재 기계에서도 이 경로 불일치를 확인했습니다. `GOTOOLCHAIN=go1.27.1 go env GOROOT`로 1.27.1의 실제 설치 위치를 구해 그 안의 `bin/go`를 `--go-bin`으로 넘기자 모델·결정론 양쪽이 다시 각각 11/11을 통과했습니다. 공개 CI도 명시적으로 1.27.1 경로를 사용합니다.
