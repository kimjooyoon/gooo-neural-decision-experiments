# Boolean condition and assignment study

One compound intent combines six existing typed structural choices:
comparison operand order, Boolean condition-local selection, Boolean assignment
target, Integer assignment target, branch-body layout and Boolean-update order.
The two languages and attempt budgets are views of this one idea. Its 64 complete
combinations use the existing eight-label structural ABI without reinterpretation
of operation labels. Frozen own models are evaluated; this study performs no
training or Laya calls.

`cohort` is generated by the Go program in this directory. The seven explicit
cases are used for bounded selection. `structural-oracle.json` and the nine
`holdout-cases.json` inputs are separate post-selection evaluation sources; they
are not passed to the native model/selection API. Structural target-label
agreement and independent arithmetic success are distinct measurements because
different internal paths can implement the same finite behavior.

The first fixture omitted the namespace's Integer entity. Native source binding
refused it before any model call; the exact failed source/documents/capture remain
under `preexecution/missing-entity`. The correction declares
`pathstudy://entity/integer`; no compiler/type rule was weakened. Preliminary
main-source smokes are under `preexecution` and are excluded from the paired
comparison. They include six actual FP32 Korean predictions, no external calls
and 7/7 explicit-case success after ten attempts; the one 8.229 ms native-stage
observation is not a performance estimate.

The independent Go comparison tool runs five repetitions of 16 cells with
balanced old-first/new-first pairs. It compares clean main and prepared binaries
on exactly the same source, model bytes, cases and budgets, retains short-budget
failures, checks exact generated-Go/arena parity, and records post-selection
arithmetic observations. The planned 160 native calls and 720 predictions are
not observed results until the source-bound capture finishes.
